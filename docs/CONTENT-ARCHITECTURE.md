# CFA L2 스터디 — 콘텐츠 구조 설계 (Content Architecture)

> 목표: **중국인 · 영어권 · 한국인** CFA Level 2 수험생 모두를 타겟한, **무료**이면서
> 유료 경쟁사보다 학습효과가 더 높은 스터디 제품.
> 원칙: *콘텐츠(형이 제공)* + *구조/틀(이 문서 + 템플릿)* 을 분리한다.

### 공통 패턴 (베낄 것)
- **LOS 단위 조직화**: 모든 콘텐츠가 Learning Outcome Statement에 매핑됨 → 커버리지 보장.
- **Vignette(item set) 연습이 L2의 핵심**: 지문 1개 + 4~6문항. L2는 100% 이 형식.
- **레슨 = 개념 + 예제 + 퀴즈** 3종 세트.
- **약점 추적**: 틀린 영역을 다시 보여줌.

### 공통 빈틈 (우리가 이길 지점)
1. **다국어 부재** — 전부 영어 단일. **EN / 中文(병음) / 한국어 3개국어**는 아무도 안 함 → 중국·한국 수험생 무주공산.
2. **최고 기능이 유료** — QBank·모의·AI튜터. 우리는 **전부 무료**.
3. **간격반복(SRS) 내장 부재** — 대부분 Anki를 따로 씀. 우리는 앱에 **내장**.
4. **수동적 텍스트** — 우리는 **능동적 인출(퀴즈/플래시카드)** 중심.

## 2. 학습과학 근거 (왜 이 구조가 더 잘 먹히나)

우리 구조는 "예쁜 노트"가 아니라 **입증된 학습법** 위에 설계한다:

- **Testing effect (인출 연습)**: 4번 다시읽기 vs 1번 읽고 3번 시험 → 1주 후 시험집단이 **50% 더 기억**. → 노트마다 **셀프 퀴즈** 필수.
- **Spaced repetition (간격반복)**: 복습 간격을 점점 늘림(1일→3일→1주→1달). → 플래시카드에 **SRS 스케줄러** 내장.
- **Interleaving (교차연습)**: 토픽을 섞어서 풀면 효과크기 g≈0.42. → "**Mixed Mode**" 랜덤 교차 퀴즈.
- **Active recall (능동 인출)**: 앞면 보고 답을 떠올린 뒤 뒤집기. → 플래시카드 앞/뒤 구조 유지.
- **Dual coding (이중부호화)**: 글+그림 함께. → 각 레슨에 **SVG 다이어그램**(CML 그래프처럼).

## 3. 정보 구조 (Information Architecture)

```
CFA L2
└─ Topic (10개: Ethics, Quant, Econ, FSA, CorpIssuers, Equity, FI, Deriv, AI, PM)
   └─ Reading / Module
      └─ LOS  ← 모든 콘텐츠의 원자단위(atomic unit)
         ├─ 📖 Lesson (트라이링구얼 노트: 개념+공식유도+다이어그램+예제+함정+요약)
         ├─ 🃏 Flashcards (LOS의 핵심 용어/공식 → SRS)
         └─ 📝 Item Set (vignette 1 + 4~6문항, 해설)
```

한 LOS = **[노트 1개 + 플래시카드 N장 + 아이템셋 1개]** 세트. 이게 반복 단위다.

## 4. 레슨 표준 템플릿 (Lesson Anatomy)

`templates/lesson-template.html` 이 이 구조를 그대로 구현한다. `pm-risk-free-rate.html` 이 완성 예시.

| # | 섹션 | 목적 | 필수? |
|---|---|---|---|
| 0 | **Eyebrow + H1(3개국어 부제)** | 토픽 위치 + 제목 | ✅ |
| 1 | **핵심 한 문장 (Hook)** | 30초 요지 | ✅ |
| 2 | **시리즈 연결 (Bridge)** | 앞/뒤 레슨과 연결 | 선택 |
| 3 | **Key Terms 표 (EN/中文拼音/한국어)** | 3개국어 용어 | ✅ |
| 4 | **Big Picture / Why** | 큰 그림·동기 | ✅ |
| 5 | **Core + 공식 유도** | `.fml` 블록으로 단계별 유도 | ✅ |
| 6 | **다이어그램 (SVG)** | 이중부호화 | 권장 |
| 7 | **Worked Example** | 숫자 예제(파이썬 검증) | ✅ |
| 8 | **함정 콜아웃 (⚠ Trap)** | 자주 틀리는 포인트 | ✅ |
| 9 | **비교 표** | CML-vs-SML 식 대조 | 권장 |
| 10 | **전체 흐름 요약 (Flow)** | 한눈 정리 | ✅ |
| 11 | **셀프 퀴즈 (자가채점)** | 인출 연습 | ✅ |
| 12 | **Footer + 저작권 고지** | 디스클레이머 | ✅ |

### 콘텐츠 작성 규칙
- **모든 숫자 예제·퀴즈 계산은 파이썬으로 검증** 후 삽입 (오답 = 신뢰도 붕괴).
- 용어는 **반드시 3개국어** (영어 원문 + 中文+병음 + 한국어).
- 저작권: CFA 커리큘럼을 **복제 금지**. 스타일만 차용, 내용은 새로 작성. Footer에 고지.
- 함정(trap)은 실제 수험생이 헷갈리는 지점 위주 (예: CML σ vs SML β).

## 5. 앱 통합 로드맵 (Build Roadmap)

기존 `index.html` 앱(플래시카드+아이템셋)에 레슨과 SRS를 얹는다.

- **Phase 1 — 레슨 레이어**: 스탠드얼론 레슨 HTML 시리즈(`pm-risk-free-rate.html` 방식) + 인덱스 페이지. *(진행중: 예시 1개 완성)*
- **Phase 2 — 3개국어 토글**: 레슨/플래시카드에 EN·中文·한국어 언어 스위치.
- **Phase 3 — SRS 내장**: 플래시카드에 간격반복 스케줄(localStorage, Leitner/SM-2 간이버전).
- **Phase 4 — Mixed Mode**: 토픽 교차 랜덤 퀴즈(interleaving).
- **Phase 5 — 약점 대시보드**: 토픽별 정답률 → 약한 LOS 재노출.
