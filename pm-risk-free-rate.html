Portfolio Management · Risk, Return & the CML/CAPM

무위험이자율 — 포트폴리오의 기준선The Risk-Free Rate in Portfolio Theory · 无风险利率与资本市场线

핵심 한 문장 — 무위험자산은 "변동성 0, 상관관계 0"인 자산이라, 위험자산과 섞으면 위험–수익이 완벽한 직선(CML)이 되고, 모든 가격모형(CAPM)의 출발점(절편)이 된다.

↔ 시리즈 연결앞의 Economics · 실질무위험이자율 노트가 "이자율이 왜 생기나"를 다뤘다면, 이 노트는 "그 무위험이자율이 포트폴리오와 자산가격 모형에서 어떻게 쓰이나"를 다룬다. 명목 Rf = 실질 Rf + 기대 인플레이션 — 아래 모형들의 Rf는 모두 이 명목 값이다.

1. 무위험자산의 두 가지 성질 (모든 것의 출발점)

포트폴리오 이론에서 무위험자산은 딱 두 가지 수학적 성질로 정의된다. 보통 단기 국채(T-bill)로 근사한다.

① 표준편차 = 0  (σf = 0)
미래 수익률이 확실 → 변동성이 없다.

② 어떤 위험자산과도 상관계수 = 0  (ρ = 0, Cov = 0)
이유: Cov(f, i) = ρ · σf · σi 인데 σf = 0 이므로 공분산이 강제로 0.

ⓘ 왜 중요한가이 두 성질(0, 0) 덕분에 무위험자산을 어떤 위험 포트폴리오와 섞어도 위험(σ)이 선형으로만 늘어난다. 곡선이 아니라 직선이 나오는 이유가 바로 이것이다.

2. 무위험 + 위험자산 = 직선 (CAL) — 수식 유도

위험 포트폴리오 i에 비중 w, 무위험자산에 (1−w)를 투자한다.

E(Rp) = (1−w)·Rf + w·E(Ri) = Rf + w·[E(Ri) − Rf] // 기대수익

분산을 전개하면 (σf=0, Cov=0 이므로 뒤 두 항이 사라진다):

Var(Rp) = w²σi² + (1−w)²·σf²(=0) + 2w(1−w)·Cov(=0)
= w²σi² ⟹ σp = w·σi // 위험은 선형!

w = σp/σi 를 위 기대수익 식에 대입하면 σp에 대한 직선이 나온다:

E(Rp) = Rf + [ E(Ri) − Rf ] / σi · σp // 이 직선이 CAL. 기울기 = 샤프비율
  • 절편 = Rf — 위험을 0으로 하면(전액 무위험) 수익은 Rf.
  • 기울기 = [E(Ri) − Rf] / σi = 샤프비율 — 위험 1단위당 초과수익. "위험의 가격."

3. CAL의 왕 = 자본시장선 (CML)

수많은 CAL 중 기울기(샤프비율)가 가장 높은 직선을 고르면, 그 직선이 효율적 프론티어에 접(接)하는 점이 바로 시장 포트폴리오 M이다. 이 최적 CAL을 특별히 자본시장선(CML)이라 부른다.

E(Rp) = Rf + [ E(Rm) − Rf ] / σm · σp // 기울기 = 시장 샤프비율 = 시장위험의 가격
CML 위 위치구성이름
Rf ~ M 사이일부 Rf + 일부 M (wM < 100%)Lending 대출 보수적
정확히 M100% 시장 포트폴리오접점 포트폴리오
M 너머(오른쪽 위)Rf로 차입해 M을 >100% 매수 (레버리지)Borrowing 차입 공격적

4. 2펀드 분리정리 (Two-Fund Separation)

위험선호가 제각각이어도, 모든 투자자는 딱 두 가지만 나눠 담는다:

  • ① 무위험자산 (Rf)
  • ② 동일한 시장 포트폴리오 M (누구에게나 같은 접점 포트폴리오)

차이는 오직 두 펀드 사이의 비중뿐. → "투자 결정(무엇을 담나 = M)"과 "위험 결정(얼마나 담나 = w)"이 분리(separation)된다. 위험이 무서우면 Rf 비중↑, 공격적이면 M을 차입해 레버리지.

5. CAPM / SML — Rf가 절편이 된다

CML이 효율적 포트폴리오를 총위험(σ)으로 가격 매긴다면, CAPM은 개별 자산을 체계적 위험(β)만으로 가격 매긴다. 그래프로는 증권시장선(SML).

E(Ri) = Rf + βi · [ E(Rm) − Rf ] // [ ] 안 = 시장위험 프리미엄(MRP)
  • 절편 = Rf (β=0일 때 기대수익). 무위험자산은 β=0.
  • 기울기 = 시장위험 프리미엄 = E(Rm) − Rf
  • β=1이면 E(Ri) = E(Rm) (시장과 동일).
ⓘ 예시Rf = 4%, MRP = 5%, β = 1.2 → E(R) = 4% + 1.2×5% = 10%.

6. Rf가 들어가는 성과지표 4형제

Rf는 "이만큼은 위험 없이 벌 수 있었다"는 기준선(hurdle)이라, 초과수익 계산의 출발점이다.

지표공식위험 척도
Sharpe 샤프(Rp − Rf) / σp총위험 σ
Treynor 트레이너(Rp − Rf) / βp체계적 β
M² (M-squared)(Rp−Rf)·(σm/σp) − (Rm−Rf)총위험 σ (수익률 단위)
Jensen's α 젠센Rp − [Rf + βp(Rm−Rf)]체계적 β

기억법: 분모가 σ면 총위험(Sharpe·M²), β면 체계적위험(Treynor·Jensen). 넷 다 Rf를 뺀 초과수익에서 시작한다.

7. 현실 보정 — 가정이 깨질 때

① 차입금리 > 대출금리
현실에서 투자자는 Rf로 빌릴 수 없고 더 높은 금리로 빌린다. → CML이 M에서 꺾인다(kink). M 왼쪽은 기울기 큰 대출선, 오른쪽은 기울기 작은 차입선.

② 실무에서 어떤 Rf를?
단기 분석엔 T-bill, 주식 자본비용(장기 CF 할인)엔 만기를 맞춘 장기 국채 수익률을 쓰는 게 일반적. 핵심은 현금흐름 기간과 만기를 맞추는 것.

③ 명목 vs 실질
모형 입력값은 보통 명목 Rf. 실질 분석이 필요하면 명목 = 실질 + 기대 인플레이션(피셔)으로 분해.
